# 迭代 PRD 模板

状态：草稿
最后更新：[日期]
范围：[本轮迭代范围]
文档角色：迭代级 PRD
更新时机：目标、范围、验收标准或关键非目标发生变化时

## 1. 背景

- 当前问题是什么
- 为什么现在要做
- 对应哪条 roadmap / backlog / layer 结论

## 2. 目标

- 本轮迭代要实现什么
- 解决哪个投资者/使用者问题

## 3. 非目标

- 这轮明确不做什么
- 哪些能力留到后续迭代

## 4. 用户价值

- 这轮完成后，用户决策质量会提升什么
- 它如何帮助识别 signal vs noise

## 5. 范围

- In scope
- Out of scope

## 6. 验收标准

- 功能验收
- 数据/语义验收
- UI/API/agent 验收

## 7. 量化与观测

- 关键 scorecard / gate
- 关键 replay / shadow / blind review 要求
- 成功门槛

## 8. 风险与约束

- 最大风险
- 外部依赖
- 明确红线

## 9. 上线与回滚要求

- rollout 方式
- fallback / rollback 原则
